# ADR-003 — Frontière Brain Engine

Date : 2026-09-29. Statut : accepté pour V0, périmètre précisé ci-dessous.

## Problème
Les appels LLM ne doivent pas intervenir dans la latence d’exécution.

## Options
Processus unique ; services séparés avec bundle immuable.

## Décision
Processus séparés ; Brain propose, gate publie, Engine exécute des règles déterministes.

## Justification
Panne LLM indépendante et permissions minimales.

## Compromis
Contrats et déploiements supplémentaires.

## Risques
Incompatibilité de features entre batch et streaming.

## Conditions de réévaluation
Avant V5 ; golden tests et benchmark Python/Rust sur même trace.
