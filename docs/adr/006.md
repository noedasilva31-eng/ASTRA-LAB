# ADR-006 — LLM model-agnostic

Date : 2026-09-29. Statut : accepté pour V0, périmètre précisé ci-dessous.

## Problème
Les capacités et modèles disponibles changent.

## Options
Modèle fixé ; routing par capacités.

## Décision
Protocol LLMProvider, aucun modèle ni SDK imposé en V0.

## Justification
Évite noms inventés et remplacement architectural coûteux.

## Compromis
Adaptateurs et tests de conformité à construire.

## Risques
Fallback peut changer qualité/coût ; contenu social adversarial.

## Conditions de réévaluation
Avant V2, vérifier documentation et accès réel du compte.
