# ADR-002 — Stockage progressif

Date : 2026-09-29. Statut : accepté pour V0, périmètre précisé ci-dessous.

## Problème
Un cluster multi-base dès V0 retarde la validation des invariants.

## Options
SQLite local ; PostgreSQL seul ; PostgreSQL + objet + OLAP.

## Décision
SQLite pour référence V1a ; PostgreSQL + objet pour V1b production.

## Justification
Transactions locales testables sans compte ni dépendance ; séparation brut/métadonnées cible.

## Compromis
Migration et tests de parité nécessaires ; BLOB SQLite non adapté au flux global.

## Risques
Pas de WORM ni haute disponibilité locale ; volumes non benchmarkés.

## Conditions de réévaluation
Avant feed réel soutenu ou second writer.
